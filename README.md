\# Práctica 1: Mi Primer Sitio Web en HTML5 (Hola Mundo) 

## 1\. Descripción 

Este proyecto contiene la estructura inicial de una página web en HTML5 desarrollada para el módulo de Lenguajes de Marcas y el Proyecto Intermodular de 1º de DAM. 

## 2\. Pila Tecnológica 

* **Lenguaje:** HTML5 / CSS3 
* **Editor/IDE:** VS Code Portable 
* **Formato de Documentación:** Markdown (.md) bajo filosofía **Docs-as-Code** 

## 3\. Estructura del Código Fuente 

El código principal de la página de bienvenida se encuentra en `src/index.html`:
 
```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Hola Mundo - 1º DAM</title>
</head>
<body>
    <h1>¡Hola Mundo! 👋</h1>
    <p>Bienvenidas y bienvenidos a 1º de DAM...</p>
</body>
</html>
